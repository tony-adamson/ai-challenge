# Аккаунт: почта, пароль, удаление

## Как сменить пароль
Откройте личный кабинет → «Профиль» → «Сменить пароль», введите текущий и новый пароль. Подключённые устройства после смены пароля продолжают работать.

## Забыли пароль
На странице входа нажмите «Забыли пароль?» и введите почту аккаунта — придёт письмо со ссылкой для нового пароля. Ссылка действует 1 час.

## Как сменить почту
Откройте личный кабинет → «Профиль» → «Почта», укажите новый адрес и подтвердите его по ссылке из письма. Если доступа к старой почте нет и войти не получается, почту меняет специалист поддержки после проверки, что аккаунт ваш.

## Удаление аккаунта
Удалить аккаунт можно в личном кабинете → «Профиль» → «Удалить аккаунт». Подписка отключается сразу, остаток оплаченного периода автоматически не возвращается — если нужен возврат, сначала обратитесь в поддержку. Через 30 дней данные аккаунта удаляются без возможности восстановления.
