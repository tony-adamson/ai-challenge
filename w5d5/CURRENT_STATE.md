### Потоки, состояние и контракты

Прежний веб-чат: HTTP ask → построение контекста из истории/памяти → LLM и MCP tool loop → события SSE → сохранение ответа и трасс. Память и история принадлежат Store; полный разговор сохраняется независимо от выбранной стратегии контекста (E-003, E-004).

RAG дня 24: vector retrieval → порог → JSON-ответ → проверка цитат → один repair при нарушении → программные источники → дополнительный judge. Не прошедший judge не блокирует сам ответ; в README зафиксированы ошибки judge и нерелевантные ответы (E-008, E-009, `w5d4/README.md`). Порог дня 24 нельзя переносить на BM25 как тот же показатель.

Книги: неизменяемый существующий SQLite-index → lexical AND, при пустом результате OR → BM25 → текст и provenance (E-010). Идентификатор книжного фрагмента задаётся source + chunk_no, а не совпадает с chunk_id vector-index. Метаданные позволяют ссылаться на книгу и страницы; формат без страниц требует честной ссылки на чанк.
