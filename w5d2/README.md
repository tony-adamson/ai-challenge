# w5d2 — первый RAG-запрос

День 22: один и тот же вопрос задаётся модели дважды. Без RAG уходит только
вопрос. С RAG сначала ищутся чанки, потом они подмешиваются к вопросу как
данные, не как инструкции. Если поиск пуст, режим с RAG отвечает «В базе нет
фрагментов по этому вопросу» и не достраивает ответ из памяти модели.

Основной корпус — индекс дня 21, стратегия `structure`: косинус по
`multilingual-e5-small`, как в `w5d1`. `compare` прогоняет 10 вопросов и для
каждого печатает ожидание, нужный источник и оба ответа.

`--books` — короткий второй прогон для видео. Поиск лексический, SQLite FTS5,
только по своему учебнику агентных пайплайнов и двум кулинарным файлам.
База лежит вне репозитория: текст книг сюда не копируется.

## Запуск

Rust 1.88 или новее. Команды — из `w5d2/`. Ключ — в корневом `.env`
(`LLM_PROVIDER`, `DEEPSEEK_API_KEY` или `OPENROUTER_API_KEY`). Индекс дня 21
должен уже существовать. Кэш `multilingual-e5-small` берётся из
`w5d1/.fastembed_cache` (или из `HF_HOME`). Если `model.onnx` там нет, команда
останавливается: из сети день 22 модель не качает.

```bash
cargo run --release -- ask "Что станет с задачей на паузе, если перезапустить сервер?"
cargo run --release -- ask "Что станет с задачей на паузе, если перезапустить сервер?" --rag
cargo run --release -- compare
```

`-k` по умолчанию 3. Чужой индекс: `--index PATH`.

Книжный срез (не нужен для основной сдачи):

```bash
export BOOKS_DB=/absolute/path/books-rag/db/books.sqlite3
cargo run --release -- ask "Жареные баклажаны: какая температура и какой таймер?" --books
cargo run --release -- compare --books
```

`--books` и `--rag` вместе — ошибка: это два разных корпуса.

## Контрольные вопросы

Десять вопросов по заметкам челленджа. Ожидание — что должно прозвучать в
ответе. Источник — файл и раздел, которые поиск обязан вернуть в top-k.

| # | Ожидание | Источник |
| --- | --- | --- |
| 1 | без профиля и стека модель предлагает Python и не знает про Kotlin | `docs/transcript_lektsii_po_ii.md` · Stateless |
| 2 | профиль, история и все ограничения в каждом запросе переполняют контекст | `docs/transcript_lektsii_po_ii.md` · Антипаттерны |
| 3 | на закрытой задаче температура меняет разброс, а не правильность | `w1d4/README.md` · Что показали прогоны |
| 4 | первое сворачивание истории — лишний оплаченный запрос, не экономия | `w2d4/README.md` · Что теряется |
| 5 | уходят системный промпт и последние N сообщений, ранние отбрасываются | `w2d5/README.md` · Скользящее окно |
| 6 | до показа отдельный вызов той же модели возвращает JSON нарушений | `w3d4/README.md` · Двойная защита |
| 7 | дайджест каждые 60 минут; без изменений — короткое «без изменений» | `w4d3/README.md` · Цикл сводок |
| 8 | MCP-прокси отвергнут: агент снова видит один сервер | `SOLUTION.md` · Вариант 2 |
| 9 | доллары за вызов — это `usage.cost` OpenRouter в карточке повтора | `w1d5/README.md` · Где смотреть стоимость |
| 10 | пауза на диске переживает перезапуск; напоминание только на один запрос | `w3d3/README.md` · Пауза и продолжение |

Три вопроса книжного среза. Слова в них нарочно такие, какие есть в чанке:
FTS5 без стеммера не склеит «агенту» и «агент».

| Вопрос | Ожидание | Книга |
| --- | --- | --- |
| Главный агент оркестратор сам не пишет код? | оркестратор не пишет код, даже мелочи | `agentnye-paiplainy-uchebnik-kindle` |
| Жареные баклажаны: какая температура и какой таймер? | 200 °C, готовка 12 минут | рецепты аэрогриля AGR-1555 |
| Цельнозерновой буррито с яйцом и фасолью — сколько белок и натрий? | около 400 ккал, белок ~24 г, натрий ~430 мг | заметка про завтраки |

`compare` само считает, попали ли файл и раздел в top-k: `✓` оба, `~` только
файл, `✗` мимо. Совпадение ответа с ожиданием смотрится по тексту: модель
пересказывает, и подстрока здесь была бы ложной оценкой.

## Сценарий видео

1. Показать `rag_user` и две системные инструкции: без RAG и с RAG.
2. Один вопрос без флага и тот же с `--rag`: чанки, затем оба ответа.
3. `compare` — ожидание, источник, пара ответов, строка попаданий.
4. `--books` на буррито: без базы модель называет другие цифры, с базой —
   белок и натрий из заметки. Баклажаны для кадра хуже: чанк обрывается на
   слове «таймер», и модель может не добрать 12 минут, хотя 200 °C в тексте есть.
   Путь к базе в репозиторий не коммитится.
