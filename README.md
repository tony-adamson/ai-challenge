# AI Advent Challenge

Задания челленджа по работе с ИИ. Одна папка — одно задание.

| Задание | Что делает | Стек |
|---------|-----------|------|
| [w1d1](w1d1) | CLI: вопрос → запрос в LLM → ответ в консоль | Rust |
| [w1d2](w1d2) | Один запрос с разным уровнем контроля ответа: формат, длина, условие завершения | Rust |
| [w1d3](w1d3) | Одна задача четырьмя способами рассуждения, N прогонов, точность по эталону; локальный веб-дашборд | Rust |

## Быстрый старт

```bash
cp .env.example .env   # и вписать реальные ключи
cd w1d1 && cargo run -- "твой вопрос"
```

Правила работы с репозиторием — в [CLAUDE.md](CLAUDE.md).
