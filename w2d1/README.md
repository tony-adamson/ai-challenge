# w2d1 — агент в веб-чате на Cerebras

Простой чат, за которым стоит агент как отдельная сущность, а не один вызов
API. Вся логика запроса и ответа — в `src/agent.rs`: там живут настройки
(модель, температура, глубина рассуждения, системный промпт), история
переписки и разбор потока Cerebras. `src/main.rs` не знает ни про историю,
ни про формат API — он только поднимает axum, отдаёт страницу и переводит
события агента в SSE.

Разделение видно по типам: наружу из агента торчат `Settings`, `Message`,
`Metrics` и поток `Event` (`Reasoning`, `Content`, `Done`, `Error`).
Заменить веб на CLI — значит переписать `main.rs` и не тронуть `agent.rs`.

Базовый системный промпт задаёт характер: Петрович, ворчливый автомеханик
с тридцатилетним стажем. Системный промпт в историю не пишется: он
подставляется первым сообщением на каждый запрос. Поэтому его можно править на ходу, не теряя контекст.
Пока идёт ответ, второй вопрос агент отклоняет: «агент занят». Если запрос
упал, вопрос из истории убирается — иначе следующий пошёл бы с двумя
репликами пользователя подряд.

## Запуск

```bash
cp ../.env.example ../.env   # вписать CEREBRAS_API_KEY
cargo run                    # поднимает http://127.0.0.1:8790 и открывает вкладку
```

```
AI Advent · w2d1 — агент на Cerebras
  ✓ .env прочитан: …/ai_challenge/.env
  ✓ модель: qwen-3.8-27b · рассуждение: none
  ✓ чат: http://127.0.0.1:8790
Ctrl-C — выход
```

Ключ берётся из общего `.env` в корне репозитория. Без него агент не
стартует и говорит, чего не хватает.

## Панель

Справа крутятся четыре настройки, каждая уходит в агента сразу после
изменения (`POST /api/settings`, у текстовых полей — с задержкой 400 мс):

- **Модель** — `qwen-3.8-27b`, `gpt-oss-120b`, `gemma-4-31b`. Под селектом
  заявленная скорость и цена за 1M токенов.
- **Температура** — 0–2, шаг 0.1, по умолчанию 0.7.
- **Рассуждение** — выключено / низкое / среднее / высокое.
- **Системный промпт** — свободный текст, кнопка возвращает базовый
  (характер Петровича).

«Очистить контекст» стирает переписку, настройки остаются. Состояние
восстанавливается при перезагрузке страницы: панель и переписка приезжают
из `GET /api/state`, а не из памяти браузера.

Настройки переживают перезапуск: после каждого удачного `POST /api/settings`
агент кладёт их в `w2d1/settings.json` (файл в `.gitignore`, история в него не
пишется — она живёт только в памяти процесса). При старте файл читается и
проходит ту же проверку, что и запрос; битый или невалидный — строка в stderr
и базовые настройки. Удалить файл — вернуться к базовым.

## Что считается

Под каждым ответом строка метрик:

- **TTFT** — от отправки запроса до первой дельты (рассуждения или ответа),
  по часам клиента.
- **Время** — полное время вызова, тоже по часам клиента.
- **Токены** — `usage.prompt_tokens` → `usage.completion_tokens` из
  последнего чанка стрима, в скобках `completion_tokens_details.reasoning_tokens`.
- **Ток/с сервер** — `completion_tokens` делить на `time_info.completion_time`,
  который присылает сам Cerebras: чистая генерация без сети и очереди.
- **Ток/с клиент** — то же деление, но на время от первой дельты до конца
  потока. Разница между двумя числами и есть накладные расходы канала.
- **Стоимость** — по прайсу Cerebras. Токены рассуждения входят в
  `completion_tokens` и тарифицируются как выход. У модели без цены на
  странице прайса стоимость не выдумывается, в интерфейсе стоит «—».

Нулевой знаменатель даёт «—», а не бесконечность: считать скорость не из
чего — честнее сказать это прямо.

## Почему рассуждение выключено по умолчанию

У `qwen-3.8-27b` на стороне Cerebras умолчание — `reasoning_effort: high`,
и в чате это заметно: на «Скажи одно слово» модель тратит десятки токенов
на размышление вслух, платных по цене выхода. Поле отправляется всегда
явно, значение по умолчанию — `none`. Включать его стоит осознанно, под
задачу, где рассуждение окупается; тогда оно приезжает отдельным потоком
`reasoning` и лежит в свёрнутом блоке над ответом.

Qwen-нативные `enable_thinking`, `disable_reasoning` и `thinking_budget`
не отправляются: Cerebras управляет рассуждением своим `reasoning_effort`.

## Модели

Список моделей и цены — константа в `agent.rs`. Справочники:
[inference-docs.cerebras.ai/models/overview](https://inference-docs.cerebras.ai/models/overview),
[cerebras.ai/pricing](https://www.cerebras.ai/pricing). API совместим с
OpenAI Chat Completions, отличается базовым URL и полем
`max_completion_tokens`.

## Дизайн

Интерфейс собран на токенах дизайн-системы Calm Intelligence (вариация Bro
Agent: фиолетовый акцент на элементах ИИ, Sage — нейтральные состояния),
шрифт Manrope, иконки монолинейные 1.5px. Логотип Cerebras — официальная
марка с cerebras.ai. Ничего внешнего страница не грузит: шрифт, стили и
логотип отдаются с того же сервера.
