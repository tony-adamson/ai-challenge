# Исследователь — оркестрация MCP-серверов

День 20: агент за один ход ищет GitHub-проекты, спрашивает DeepWiki об их
устройстве, делает обзор с выдержками, сохраняет Markdown-файл и по просьбе
отправляет сообщение владельцу в Telegram. В окне «Размышление» каждый шаг
подписан сервером; вызовы маршрутизируются по каталогу трёх серверов:

- `research` (`/mcp`): `search_repositories`, `summarize(search_id, notes?)`,
  `save_to_file(summary_id, filename)`, `watch_create`, `watch_list`,
  `watch_delete`, `watch_summary`. Поиск возвращает `search_id` и имена
  репозиториев; обзор использует сохранённый поиск и при наличии `notes` —
  выдержки DeepWiki. Файл лежит в `data/reports/` и доступен по чипу под ответом.
- `deepwiki` (`https://mcp.deepwiki.com/mcp`): только `ask_wiki_question`;
  `repoName` берётся из результата поиска в формате `owner/repo`.
- `notify` (`/notify`): `send_telegram(text)` отправляет сообщение владельцу,
  заданному через `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

До 8 вызовов инструментов за ход. «План» по умолчанию выключен; при включении
инструменты доступны на этапе выполнения после утверждения плана. Скачивание
файлов и веб-интерфейс требуют входа по TOTP.

## Запуск локально

Rust 1.88 или новее. Команды — из `w4d5/`. Ключи и адреса серверов — в
корневом `.env` (шаблон `../.env.example`); для обзора нужен `DEEPSEEK_API_KEY`.
Для входа один раз выполнить `cargo run -- --totp-init`, строку `TOTP_SECRET=…`
добавить в корневой `.env`, otpauth-ссылку — в приложение-аутентификатор.

Терминал 1 — MCP-сервер (`/mcp` и `/notify` на `127.0.0.1:8800`):

```bash
cargo run -- --mcp-server
```

Терминал 2 — веб-интерфейс:

```bash
cargo run
```

Открыть `http://127.0.0.1:8799` и ввести код из приложения. Без `TOTP_SECRET`
веб-режим не стартует. Для отправки в Telegram нужны оба `TELEGRAM_*` значения.

## Где смотреть код

- `src/mcp.rs` — `SERVERS`, `merge_catalogs` и подключения MCP.
- `src/agent.rs` — маршрутизация вызовов, подключения на ход, промпт и трассы.
- `src/notify.rs` — сервер `/notify` и `send_telegram`.
- `src/watch.rs` — инструменты `research`, `notes` в обзоре и хеш в шапке файла.
- `static/index.html` — шарик и окно «Размышление» с метками серверов.

## Проверки

Из папки `w4d5/`:

```bash
cargo test
cargo clippy --all-targets -- -D warnings -A clippy::too_many_arguments -A clippy::double_ended_iterator_last
cargo build --release
```

Ручной прогон: цепочка с выключенным «Планом», `repoName` из результата поиска,
метки шагов, шапка скачанного файла и доставка Telegram; после перезагрузки
проверить шаги и файл, затем открыть старый чат без меток сервера.

## Деплой

Службы `w4d5-mcp`/`w4d5-web`, см. `deploy/` (вне этой фазы).

## Ограничения

Exa недоступен из РФ; DeepWiki знает только проиндексированные репозитории.
`notes` — до 3000 символов. Каталог не кэшируется, пока хотя бы один сервер
недоступен. `summarize` требует DeepSeek независимо от провайдера чата.

## Сценарий видео

1. Показать код `SERVERS`, маршрутизацию, `notes` и `/notify`, войти по TOTP.
2. С выключенным «Планом» отправить одним сообщением: «Найди Rust-проекты для
   полнотекстового поиска, для двух лучших спроси у DeepWiki, как устроен
   индекс, сделай обзор, сохрани в файл rust-search-deepwiki и пришли мне в
   Telegram».
3. В «Размышлении» показать метки `research`/`deepwiki`/`notify`, сверить
   `repoName` с результатом поиска; скачать файл и показать шапку с
   `notes sha256`, затем сообщение в Telegram.
