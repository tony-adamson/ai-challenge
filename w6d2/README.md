# День 27: локальная LLM в Telegram-боте

Муса — Telegram-бот, дерзкий дагестанец-стендапер с дагестанским говором (вацок, жи есть, абдал, сабур делай): отвечает коротко, панчем по твоим словам, мат — 1–2 слова на ответ, цепляется к тому, что ты написал. Каждый ответ генерирует локальная модель `mlx-community/gemma-4-e4b-it-4bit` на `mlx_lm.server` (OpenAI-совместимый API на `localhost:8080`). Облачных моделей нет: весь стек — бот, сервер модели и веса — работает на маке, наружу ходит только Telegram.

Национальность и религию Муса не трогает, религиозных слов не говорит и всерьёз не угрожает — это зашито в системный промпт.

Владельца (`TELEGRAM_CHAT_ID`) Муса знает как создателя: в переписке для модели его строки помечены `Антон (создатель): …`. Создателю Муса предан, но с ним такой же дерзкий: жёстко подкалывает без настоящих унижений, на предложение кого-то прожарить рвётся в бой и заступается за создателя, если на него наезжают.

## Установка

Сервер модели берётся из venv дня w6d1 (`w6d1/.venv/bin/mlx_lm.server`). Если его нет:

```sh
cd ../w6d1
python3 -m venv .venv
.venv/bin/pip install mlx-lm
.venv/bin/mlx_lm.generate --model mlx-community/gemma-4-e4b-it-4bit --prompt "Привет"   # скачать веса, 4.8 GB
```

Запускать сервер руками не нужно: если на `localhost:8080` никто не отвечает, бот поднимает `mlx_lm.server` сам (логи — `data/mlx_server.log`) и останавливает при выходе. Уже запущенный сервер бот использует и не трогает.

## Бот в Telegram

1. В @BotFather: `/newbot` — получить токен.
2. Чтобы бот видел все сообщения в группе: `/setprivacy` → выбрать бота → `Disable`. Если бот уже в группе — удалить и добавить заново, иначе настройка не применится.

В корневой `.env`:

```
MUSA_BOT_TOKEN=...       # токен Мусы (не TELEGRAM_BOT_TOKEN — тот у бота сводок w4d3)
TELEGRAM_CHAT_ID=...     # твой user id: в личке Муса отвечает только тебе
```

## Запуск

```sh
cargo run --release
```

При старте бот находит или поднимает сервер, делает прогревочный запрос и печатает:

```
Муса на связи @musa_bot · модель mlx-community/gemma-4-e4b-it-4bit · прогрев 9120 мс
```

## Когда Муса отвечает

- Личка: только владельцу. Остальным — «с незнакомыми не базарю», без запроса к модели.
- Группа: если в тексте есть «Муса» или @username бота, если ответили на его сообщение, и примерно в 10% случаев сам. Отвечает reply-ем.
- `/roast @username` или `/roast` ответом на сообщение — прожарка по последним сообщениям человека. Если человек молчал — прожарка за молчание.

Модель видит последние 16 сообщений чата, включая свои реплики. На каждого участника бот копит до 50 последних сообщений в `data/dossier.json` — из них и берётся материал для `/roast`. Если модель недоступна, Муса отвечает в роли и коротко пишет реальную причину.

## Без Telegram

Один запрос к модели с той же персоной, от имени создателя:

```sh
cargo run --release -- say "ты тупой бот"
```

## Монитор

На каждый ответ в терминал пишется строка с метриками: чат, кому, триггер (`private` / `mention` / `reply` / `random` / `roast`), токены ответа, скорость (токены ответа на полное время запроса) и время ответа. Под ней идут входящее сообщение (первые 80 символов) и ответ Мусы целиком:

```
[Пацаны] → Антон · mention · 34 ток · 21.3 ток/с · 1596 мс
    Антон: Муса, как тебе мой новый код?
    Муса: э, брат, код как код, вацок, главное что ты сам его писал, бля
```
