# «Эми» — продукт недели 7

Локальный ассистент разработчика для одного пользователя. Запускается в папке
репозитория, открывает окно `127.0.0.1:8765` с токеном `?t=`. Целевой проект —
папка запуска. Данные — в `<git-common-dir>/emi/`.

Источник решений — `~/MyProjects/a-harness/GRILL.md` и `SOLUTION.md` (кроме D-9,
голос отложен). После челленджа код переезжает в a-harness.

## Решения

- Не CLI, а приложение: вкладка браузера, без Electron.
- Язык — Rust. Код — `w7d1..w7d5`, каждый день копия предыдущего + фича.
- Мозг — Gemini Flash (`gemini-3.8-flash`) через OpenAI-совместимый эндпоинт
  `generativelanguage.googleapis.com/v1beta/openai/`, fallback — DeepSeek.
- Локальная модель не нужна. Надёжность важнее скорости.
- Каждый день — M-срез со своим scope-контрактом.
