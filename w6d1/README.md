# День 26: локальная LLM

Модель `Qwen3.5-9B` (4-bit, 5.6 GB) запускается локально на MacBook Air M2 / 16 GB через [MLX-LM](https://github.com/ml-explore/mlx-lm) — фреймворк Apple для Apple Silicon. К ней можно обратиться из CLI и по HTTP API в формате OpenAI Chat Completions. Ключи и сеть для ответов не нужны: сеть нужна один раз, чтобы скачать веса с Hugging Face в `~/.cache/huggingface`.

## Почему MLX и эта модель

- Модель целиком держится в unified memory (общая RAM для CPU и GPU). На 16 GB комфортный потолок — 8–9B в 4-bit; 27B в 4-bit весит 15 GB и не помещается.
- MLX — нативный фреймворк для Apple Silicon; `mlx_lm.server` отдаёт тот же OpenAI-формат, что DeepSeek/OpenRouter в прошлых днях.
- Режим «размышлений» Qwen3.5 выключен (`enable_thinking: false` в каждом запросе): иначе модель тратит сотни токенов на черновик на английском и путается в фактах о себе.

## Установка

Из каталога `w6d1`:

```sh
python3 -m venv .venv
.venv/bin/pip install mlx-lm
```

Проверено: Python 3.14.5, mlx 0.32.3, mlx-lm 0.32.0, macOS 26.6.

## CLI

Первый запуск скачивает модель:

```sh
.venv/bin/mlx_lm.generate --model mlx-community/Qwen3.5-9B-MLX-4bit \
  --chat-template-config '{"enable_thinking": false}' \
  --prompt "Привет! Ответь одним предложением: кто ты?"
```

## HTTP API

В одном терминале — сервер на `localhost:8080`:

```sh
.venv/bin/mlx_lm.server --model mlx-community/Qwen3.5-9B-MLX-4bit
```

В другом — три запроса разной сложности (факт → объяснение → задача на рассуждение), нужен `jq`:

```sh
./requests.sh
```

## Окно чата

Electron-приложение в стиле w5d5: один чат «вопрос — ответ» без настроек. Ответ печатается по мере генерации; под каждым ответом — токены, ток/с, время до первого токена; в сайдбаре — последняя и средняя скорость и сумма токенов. Кнопки на стартовом экране задают три запроса разной сложности.

Для сравнения в сайдбаре можно выбрать вторую модель — `gemma-4-e4b-it-4bit` (Google, 4.8 GB). Скачать её заранее: `.venv/bin/mlx_lm.generate --model mlx-community/gemma-4-e4b-it-4bit --prompt "Привет"` (иначе скачается при первом вопросе). Сервер держит в памяти одну модель и перезагружает её при переключении, поэтому первый ответ после смены идёт на ~10 с дольше. Смена модели начинает новый разговор, чтобы вторая модель не видела ответов первой; счётчики скорости ведутся по каждой модели отдельно.

```sh
npm install
npm start
```

Отдельно запускать сервер не нужно: если на `localhost:8080` никто не отвечает, `main.js` сам поднимает `.venv/bin/mlx_lm.server` (логи — в этом же терминале) и останавливает его при закрытии окна. Уже запущенный вручную сервер приложение использует и не трогает. Страница `chat.html` обращается к серверу напрямую; пока он недоступен, индикатор в сайдбаре красный, а вопрос получает сообщение, что делать.

## Замеры на M2 / 16 GB

| | |
|:--|:--|
| Генерация | Qwen3.5-9B ~16–19 токенов/с · Gemma 4 E4B ~26–32 токенов/с |
| Пиковая память | Qwen 5.2 GB · Gemma 4.3 GB |
| Простой запрос (5 токенов) | 2 с |
| Объяснение (109 токенов) | 8 с |
| Задача про поезда (667 токенов) | 41 с, ответ 12:10 — верный |
